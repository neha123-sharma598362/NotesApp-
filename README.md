# NotesApp 📝

A simple and responsive Notes Application built using React, Node.js, Express.js, and MongoDB. It allows users to create, view, edit, and manage their notes.

## Features

- Create new notes
- View all notes
- Edit existing notes
- Move notes to Trash
- Restore notes from Trash
- Permanently delete notes
- Search notes by title
- Responsive user interface
- REST API integration using Axios

## Tech Stack

**Frontend**
- React.js
- JavaScript
- Tailwind CSS
- Axios

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose

## Installation and Setup

### 1. Clone the Repository


git clone YOUR_GITHUB_REPOSITORY_URL
cd NotesApp


### 2. Install Dependencies

Install the dependencies required by your frontend and backend. If both have separate `package.json` files, run `npm install` in each respective folder.

### 3. Start MongoDB

Make sure MongoDB is running on your computer.

### 4. Start the Backend

Open a terminal in the backend folder and run:


npm install
node server.js


### 5. Start the Frontend

Open another terminal in the frontend folder and run:


npm install
npm run dev


Open the local URL shown in the terminal to use the application.
